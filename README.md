# ArchiCode's model

ArchiCode's own architecture — why it exists, what it offers, how it is built and where it runs — modelled in ArchiMate 4.0 with ArchiCode itself.

- `archicode.yml` — the manifest: the model's name and its notation
- `model/` — the elements and their relations, a package per folder
- `views/` — the views
- `config/` — specializations, properties, dictionaries, validation rules and stylesheets

The model is edited with ArchiCode, and changed by pull requests into `main`.
